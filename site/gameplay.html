贰 · 核心机制

六大核心系统

一个关于信息、权力与生存的复合博弈系统

壹

信息过滤系统

你看到的，是官员想让你看到的。

玩家的信息来源只有两类文件，它们之间存在巨大的信息差：

奏折（Letters）

地方官员递交的正式报告。这些文本经过了严重的粉饰、推诿和"润色"。官员会在其中：

  • 夸大自己的勤勉与功绩
  • 淡化审讯中的刑讯逼供
  • 将编造的供词包装为"证据确凿"
  • 巧妙推卸案件未能按时告破的责任

案卷（Cases）

基层审讯的原始记录。保留了犯人受刑时的真实惨状和胡言乱语。需要消耗特定资源（如派出密探）才能调阅。其中包含：

  • 嫌犯在酷刑下的原始对话
  • 生理状态变化的实时记录
  • 前后矛盾、胡编乱造的"供述"
  • 刀笔吏润色前的案卷底稿

游戏的核心体验在于信息审计——在"虚假的奏折"与"混乱的原案"之间比对，像批阅奏章的真实帝王一样，在字里行间寻找官员撒谎和推卸责任的逻辑破绽。

贰

朱批施压系统

你的每一个字，都是压在官员头上的千钧之力。

玩家通过对奏折下达"朱批"来施加政治压力。朱批分为三种类型，对应不同的压力等级：

指示

明确指示

告诉官员你的期望——"此案务必限期告破"、"严查妖党余孽"。这会增加官员的结案压力。

系统效果 提升官员 Agent 的政治压力参数 → 加大用刑力度 → 嫌犯生理属性加速扣减
斥责

严厉斥责

"糊涂！""此奏荒谬！""办理不力，着即严加查办！"——直接威胁官员的仕途。

系统效果 官员 Agent 可能产生"恐慌"情绪 → 在奏折中更加美化案情 → 在审讯中更激进
革职

革职警告

"再办不成，便提头来见"。最高级别的压力，相当于"政治死刑"威胁。

系统效果 官员 Agent 进入"自保模式" → 不择手段结案 → 可能直接编造案卷

政治压力的传导不是线性的。一个"斥责"朱批可能让谨慎的官员变得激进，也可能让狡猾的官员学会更精致的粉饰——这取决于 Agent 的个性和过往经历。

叁

AI 涌现行为

不是代码触发，而是自主决策。

这是《叫魂》最核心的技术创新：游戏中所有 Agent 的行为都不是通过预设的规则树或硬编码触发器产生的，而是由大语言模型（LLM）在理解自身处境后自主涌现的。

嫌犯的"自由意志"

嫌犯 Agent 没有被硬编码为"当疼痛 > 70 时自动招供"。相反，系统将当前的生理状态以自然语言描述注入提示词：

提示词注入示例
你正处于强烈的生理痛苦中，神志恍惚。
你感到喉咙异常干涩。
审讯官说：再不说实话，还有更厉害的等着你。

AI 在此基础上自主决定：是继续死扛？还是编一个故事换取片刻喘息？是攀咬一个路人？还是供出一个真正的仇人？

官员的"理性选择"

官员 Agent 同样不被硬编码。他们接收的上下文包括：

  • 皇帝朱批的具体内容和语气
  • 当前案件的政治敏感度
  • 审讯记录中嫌犯的真实供述
  • 自身的仕途处境和过往记忆

基于这些信息，官员 Agent 自主决定如何在奏折中呈现案件。他可能选择如实上报，也可能选择选择性遗漏、美化措辞，甚至编造不存在的"进展"。

肆

双轨奏折系统

一明一暗，两张面孔。

清代的奏折制度分为两种类型，它们在游戏中对应不同的信息可见度和行为约束：

明发奏折

全国官员可见

公开的官方报告。所有官员都能读到，因此官员在撰写明发奏折时会：

  • 展示自己的勤勉和能力
  • 使用官方话语体系
  • 避免任何可能自陷的文字
  • 影响其他官员 Agent 的行为——他们读到后会调整自己的策略

密折

仅通信双方可见

通过密折系统暗中传递的信息。这是玩家审查破绽的核心来源。官员在密折中会：

  • 承认困难和不确定
  • 暗中推卸责任或暗示他人失职
  • 请求从宽或暗示需要更多资源
  • 展现与明发奏折截然不同的叙事

核心玩法：比对同一官员的明发奏折和密折——两份文件之间的矛盾和差异，就是信息过滤的"破绽"。善于发现这些破绽的玩家，才能真正看透这场政治博弈的本质。

伍

生理属性系统

不是代码的触发器，而是影响灵魂的砝码。

嫌犯 Agent 拥有四项真实的生理属性，它们不是硬编码的行为阻断器，而是通过提示词自然地影响 Agent 的决策过程：

属性 范围 提示词转化 行为影响
疼痛 Pain 0 — 100 隐隐作痛 → 钻心剜骨 → 意识模糊 影响思维清晰度与决策理性
健康 Health 0 — 100 尚能支撑 → 气息奄奄 → 死亡 决定 Agent 能否继续受审
饥渴 Thirst 0 — 100 口渴 → 喉咙如火烧 → 愿做任何事换水 削弱意志力，增加招供倾向
饥饿 Hunger 0 — 100 饥饿 → 虚弱 → 无法集中 影响供述的连贯性和可信度

刑罚 API 对这些属性的扣减是确定性的（如"夹棍"固定增加 30 疼痛、减少 15 健康），但属性值对 Agent 行为的影响是模糊的、涌现的——这正如同真实世界中，痛苦对人的影响不是"到达阈值就崩溃"这么简单。

陆

终端沉浸体验

纯文字，恰如一个批阅奏章的帝王。

《叫魂》采用纯 TUI（终端文本界面）实现，完全摒弃图形界面。这种极简的设计选择并非妥协，而是一种刻意的审美决策：

信息密度最大化

纯文字界面迫使玩家专注于信息本身——措辞的微妙差异、前后的逻辑矛盾、刻意省略的细节。没有视觉干扰，只有冰冷文字。

历史沉浸感

黑底白字的终端界面复刻了"案牍查阅"的冰冷氛围。你面对的不是游戏画面，而是一份份需要你亲自审阅的公文。

交互设计

使用 Textual 框架构建高质量的终端面板。交互通过命令行指令实现，例如：

/torture 夹棍 "说！到底是谁教你妖术的？"

这种输入方式本身就是一种"权力"的体现——你输入命令，底层执行。正如一个帝王不会亲自动手，只会下达指令。
