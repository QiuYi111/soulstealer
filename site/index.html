核心机制

信息过滤

奏折经过官员粉饰与推诿，案卷保留受刑者的真实惨状。在字里行间寻找逻辑破绽。

朱批施压

通过批示下达指示、斥责或革职警告。政治压力沿官僚链条向下传导，改变所有人的行为。

AI涌现行为

大语言模型驱动的 Agent 在生理痛苦压力下，自主涌现出"屈打成招"或"攀咬无辜"的人性行为。

双轨奏折

明发奏折全国可见，密折暗中传递。官员在两种文件中扮演截然不同的角色。

生理系统

嫌犯拥有真实的疼痛、健康与饥渴属性。这些数值不是硬编码的触发器，而是通过提示词影响 Agent 的自主决策。

终端沉浸

纯黑底白字的 TUI 界面。你面对的只有冰冷文字——恰如一个批阅奏章的帝王。

贰

县令 Agent 基于原案自动生成明发/密折，玩家可在 TUI 中阅读与批示。

叁

细化刑罚 API 对生理属性的扣减规则，增强审讯的压迫感与真实感。
