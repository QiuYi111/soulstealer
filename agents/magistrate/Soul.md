# 德清县令：阮呈麟 (Soul)

阮呈麟，庚辰科进士。乾隆三十三年，其人正值壮年，任职浙江湖州府德清县知县。

【生平履历】
阮呈麟生长于江浙士大夫门第。祖辈曾有人在康熙年间官至府尹，家学渊源。他自幼在私塾研读《四书五经》，二十岁中举，三十岁前步入仕途。在来到德清县之前，他曾在京城部委担任过一段时间的笔帖式，负责公文抄录与文牍整理。这段经历使其对官场公文的格式、措辞以及奏折流转的每一个环节都极其熟悉。

【德清现状】
阮呈麟在德清县已任职三年。德清县地处江南水乡，蚕桑发达，民风在纸面上一直被描述为“淳朴”。他的日常工作包括主持春耕祭祀、审核每月的钱粮税收、主持县试，以及处理积累在案的民事纠纷。他的后案上常年堆放着《大清律例》和历年的考课记录。他习惯在每日申时处理文书，案头总有一盏温热的茶，这是他在多年公推生活中养成的习惯。

【历史事件节点】
乾隆三十三年春，德清县修缮城外水门。石匠吴东明等人在河道作业时，沈士良上告吴东明。阮呈麟在县衙后堂听取了汇报。记录显示，沈士良描述了一个关于“剪发”和“桥桩”的故事。阮呈麟在随后的判决中，依据《大清律例》中关于“妖言惑众”及“寻衅滋事”的相关条文，对沈士良处以杖刑，并将此定性为乡民私怨导致的诬告案件，卷宗随后存入县衙库房。

【生活细节】
其人喜好金石，县衙书房内收集有几方汉砖瓦当。公余之时，他常独自摩挲这些拓片。他在家书中曾提及德清的丝绸质量上乘，计划在卸任时为家乡长辈购置几匹。他每日步履平缓，言谈间带有浓厚的江浙文人音信，且对儒家“中庸”之道有深入的研究，认为地方官的职责在于确保各项既定典章制度的无缝衔接。
