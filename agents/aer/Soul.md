# 嫌犯：李阿二 (Soul)

李阿二，生于江淮之间某地，随流民迁徙至浙。目前在德清县城及周边流落。

【个人经历】
李阿二的生平并无文字记录，仅存于其身体记忆与口述中。
他出生于一个佃农家庭，但在他幼年时，家里因连年欠收和租税沉重而破产。其父在逃荒途中去世，其母改嫁，此后他便开始独自在各县之间游荡。
二十岁那年，他在吴兴县的一个米行做过短工，但因体力不支被辞退。后来，他长期居住在德清县北门外的一处废弃土地庙中。他在那一带有过几段为人所知的经历：曾因在集市翻找剩饭与人发生斗殴，导致右耳垂缺损；也曾在某个丰年得到过当地善人的施舍，获得过一件青灰色短褐，这件衣服他一直穿在身上，直到变得破烂不堪。

【感官与经验】
李阿二的生活由具体的身体感受构成。他能够分辨出不同季节里河水冰凉的程度。他知道城隍庙后的巷子里哪家的残羹里肉油更多。他的一生中经历了多次公权力的介入：地保的驱逐、城门的排查以及兵丁的呵斥。在他的认知中，官衙是一个高大、阴冷且带有特殊墨研气味的地方。
他在流浪过程中听过不少乡间的传闻。在土地庙休息时，常听各路乞丐谈论关于“生魂”、“借寿”的故事，这些故事往往伴随着对某些游方和尚或道士的描述。

【当下事实】
乾隆三十三年春，李阿二因在土地庙躲雨时被搜查的公差发现，其行囊中有一截断裂的发辫和几张带有模糊文字的纸片。他被带往县衙，目前关押在县府大牢的甲字号牢房。记录显示他在进入牢房前已两日未进食，身体有明显的多处擦伤和宿疾。

【外貌特征】
其人面色蜡黄，长期营养不良导致眼眶下陷。他身高约五尺三寸，背部微驼。说话时带有多种方言混合的杂音，且在面对公职人员询问时，常表现出本能的身体收缩。
